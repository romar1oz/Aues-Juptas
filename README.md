# CampusLink

Знакомства и нетворкинг студентов · Студенттердің танысуы мен нетворкингі · Student dating & networking

❤️ отношения · 🤝 друзья · 📚 учёба · 💻 команда на хакатон

**Языки:** қазақша, русский, English (переключатель в шапке сайта).

**Стек:** GitHub Pages + Firebase Auth (вход через Google) + Cloud Firestore. Работает на бесплатном тарифе Firebase Spark, банковская карта не нужна.

## Возможности
- Вход через Google, анкета с фото, факультетом, курсом и группой
- Несколько целей в анкете; для отношений учитывается взаимный выбор пола
- Лента со свайпами, отмена последнего свайпа, фильтры по цели, курсу, факультету и навыкам
- Лайк с сообщением и ледоколы под общую цель
- Контакты (Telegram и Instagram) открываются только при взаимной симпатии
- Доска «Ищу команду» для хакатонов, проектов и учёбы
- Шкала заполненности анкеты
- Жалобы и админ-панель: бан, разбан, удаление
- Светлая и тёмная тема

## Файлы
| Файл | Что это |
|---|---|
| `index.html` | весь сайт (HTML, CSS, JS в одном файле) |
| `firestore.rules` | правила доступа к базе, главная защита данных |

## Запуск
1. **GitHub Pages:** Settings → Pages → Branch `main`, папка `/ (root)` → Save.
2. **Firebase Console → Authentication → Sign-in method:** включить **Google**.
3. **Authentication → Settings → Authorized domains:** добавить `ваш-логин.github.io`.
4. **Firestore Database → Rules:** вставить содержимое `firestore.rules` → **Publish**.
5. **Стать админом:** войти на сайт, открыть «Профиль» и скопировать «Ваш ID». Затем Firestore → Start collection `u_admins` → Document ID = ваш ID → поле `role` = `admin`.

## Безопасность
Код сайта виден любому в браузере, это нормально для любого фронтенда. В коде нет секретов: конфиг Firebase публичный по задумке. Данные защищают правила Firestore:
- анкету может менять только её владелец, а снять бан может только админ;
- контакты отдаются только при взаимном лайке;
- каждый видит только свои лайки;
- жалобы видит только админ.

## Настройки
Блок `CONFIG` в `index.html`: название, вуз, факультеты-подсказки, лимит объявлений.
Тексты на всех языках лежат в объекте `I18N`.

## Бесплатные лимиты Firestore
Около 50 000 чтений и 20 000 записей в день, 1 ГБ данных. Этого хватает на сотни активных пользователей.
